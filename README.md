## 🚀 快速开始 / Quick Start

```bash
# 1. 克隆仓库到本地
git clone https://github.com/WangFei-01/portfolio.git
cd portfolio

# 2. 选择本周目录,例如:
cd week01_dev-env-and-tools

# 3. 在里面写代码、建 README 记录心得后:
git add .
git commit -m "week01: 完成开发环境搭建实验"
git push
```
